# Thobani Ndlovu

Personal website for Thobani Ndlovu — architectural professional, TEDxDurban curator, speaker and writer.

The site is deliberately lightweight: plain HTML, CSS and JavaScript, with no build step. It is ready for GitHub Pages through the included deployment workflow.

## Editing

- Main content: `index.html`
- Visual design: `styles.css`
- Images and favicon: `assets/`
- Mobile navigation: `script.js`

## Publishing

Push the repository to a GitHub repository using the `main` branch, then enable **GitHub Pages** with **GitHub Actions** as the source in the repository settings.
